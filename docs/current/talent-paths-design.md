# 天赋流派设计评定：剑修 / 丹修 / 符修 / 体修

评定的依据不是品类惯例，而是**本项目现有的战斗公式与战斗数值常量**。
先列出会约束设计的硬参数，再给四派的定位、能力映射、优缺点与分支点。

## 零、先看约束设计的六个硬参数

全部取自 `src/modules/combat/services/combat-mechanics.ts` 与 `damage-formula.ts`：

| 机制 | 公式 / 常量 | 设计含义 |
| --- | --- | --- |
| 防御减伤 | `100 / (100 + def)` | 收益**递减**：def 100 → 减伤 50%，def 300 → 75%，再往上性价比急降 |
| 格挡率 | `block / (block + 600)`，上限 **45%** | 需要很高的 block 才接近上限 |
| 格挡减伤 | `0.2 + block/(block+800) × 0.35`，上限 **70%** | 与格挡率是两条独立的收益线 |
| 格挡被克制 | 穿透压制系数 `(pen/(pen+650)) × 0.62` | **穿透是真·克星**，且 `PENETRATION_SOFT_CAP = 500` |
| 幸运 | 暴击率 `luck/(luck+900)`，倍率 `1.45 + luck/3000` | 同时供给暴击率与暴击伤害，但都有上限，属稳健收益 |
| 神识 | 压制 ±**0.025**；治疗 **+2.15/点**；地图视野 | **治疗收益远大于战斗收益**——这是符修设计最大的陷阱 |

另外两个必须知道的前提：

- **境界压制已经在跑**：`realmGap clamp(-4, +5) × 0.04`，总压制 `clamp(-0.14, +0.18)`。
  所以「境界压制」不需要新增机制，流派设计要在此基础上叠加，而不是推翻它。
- **技能消耗法力已实现**（`mpCost` 贯通战斗/UI/AI），技能类型是自由文本
  （`skills.skill_type`，默认 `attack`）——流派可以引入自己的技能类型，无需改表。

## 一、四派定位总览

| 流派 | 一句话定位 | 主属性 | 核心资源 / 机制 | 战斗角色 |
| --- | --- | --- | --- | --- |
| 剑修 | 以攻代守，一剑决生死 | 攻击、穿透、速度 | 法力（高消耗） | 爆发 / 速杀 |
| 丹修 | 以药续命，胜在持久 | 气血、丹毒上限 | 丹药品级与丹毒 | 续航 / 经济 |
| 符修 | 以识观天下，控场制敌 | 神识、法力上限 | 视野情报、符箓消耗 | 控制 / 情报 |
| 体修 | 以身铸墙，反守为攻 | 气血、防御、格挡 | 反击 / 免控 | 站桩 / 承伤 |

## 二、剑修（剑修一脉·斗战）

**能力映射**

- 属性倾斜：`attack`、`armorPenetration`、`speed`
- 机制倾斜：连携追击（法宝追击 / 追加攻击）触发概率提升；技能 `skillType = sword`
- 乘区：走已实现的 `skillDamageBonus` 与装饰层 percent

**优点**

- PvE 效率最高：出手快 + 爆发高，挂机刷怪轮次最少
- **天然克制体修**：穿透直接压制格挡率与格挡减伤，体修的立身之本被点名
- 装备收益线性：不像防御那样递减，攻击越高越直接

**缺点**

- 身板脆：缺 `maxHp / defense / block`，Boss 与 PvP 站桩吃大亏
- 法力吃紧：法力消耗已实现且贯通 AI，持久战容易断档
- **穿透溢出**：`PENETRATION_SOFT_CAP = 500`，超过后几乎无收益，流派给的穿透必须参与统一封顶，否则玩家后期白堆

**需要的护栏**：流派给的穿透加成要折算成「有效值封顶 500」，超出部分不生效或转极少量攻击。

## 三、丹修（药王一脉·长生）

**能力映射**

- 属性倾斜：`maxHp`、丹毒上限与恢复速度
- 机制倾斜：炼丹产出高品级概率提升；自身服药效果倍率提升；丹毒上限提高
- 经济线：高品级药品可以出售，天然的经济优势

**优点**

- 续航最强：别人靠回城/等待，丹修靠吃药，长线兑换率极高
- 容错高：血量厚 + 能自我补给，容错率高
- 经济好：高品级药品是硬通货

**缺点**

- 输出最弱：不提供攻击/穿透/奇袭任何一种乘区
- 依赖资源：药品用尽就打回原形，背包压力也是隐性成本
- 乐趣偏弱：缺乏战斗中的主动操作感

**最需要警惕的机制**

「自身服药效果倍率」如果给太高，会变成**无限续航**，直接废掉丹毒机制与战斗节奏。
建议只放大「品级与炼制产出」，不放服用效果，或者即便放也封顶在一个很小的数值。

## 四、符修（灵符一脉·洞察）

**这是四派里设计风险最大的一派，原因就是那行 `HEAL_SPIRITUAL_SENSE_RATIO = 2.15`。**

**能力映射**

- 属性倾斜：`spiritualSense`、`maxMp`、`artifactDamageBonus`
- 机制倾斜：地图视野扩大（神识已在 `map-vision` 里决定 `clearViewSize` 与迷雾等级）、
  敌人/资源在迷雾中显形、符箓类消耗道具
- 乘区：法宝增伤（已存在 `artifactDamageBonus`）

**优点**

- **情报优势独一无二**：本项目有一张 866 格的探云舟地图和带迷雾的地图机制，
  神识直接决定看多远。能先发现稀有怪、秘境入口的流派，在非战斗维度非常强
- 控制与消耗：法力上限高，适合打持久消耗
- 非战斗收益不影响战斗平衡，是安全的差异化

**缺点**

- **战斗木桶短板是最短的**：神识对压制的加成上限只有 ±0.025，几乎是装饰品
- 若不干预，神识会把符修推向「最强治疗」——治疗公式 `+2.15 × 神识`，
  这与「符修 = 洞察/控场」的定位完全错位
- 身板脆，且缺乏爆发

**建议的调整**：符修的神识待遇应绑定**视野、控制成功率、法宝伤害**，
而不是白拿治疗量。否则会出现「符修兼职奶妈且比丹修还能奶」的错位。
具体做法可以是在治疗结算时，仅让流派指定的系数生效（例如剑修/丹修共享原生比例，符修另算）。

## 五、体修（淬体一脉·不动）

**能力映射**

- 属性倾斜：`maxHp`、`defense`、`block`
- 机制倾斜：受击反击（反弹伤害）、低消耗（普攻不耗法力）、部分免控

**优点**

- 站桩与挂机最稳：不受法力束缚，离线/挂机表现最稳
- PvP 难被秒：三重防御（血量、防御减伤、格挡）叠加
- 反击机制让「挨打」本身产生价值，玩法手感独特

**缺点**

- **输出成长最慢**：三重防御都是收益递减的曲线（尤其 `100/(100+def)`），
  投入同样的资源，输出侧的提升远低于剑修
- 被剑修点名克制：穿透同时打掉格挡率与格挡减伤，体修的核心投入被折价
- 缺爆发：拖入持久战（比如 Boss 有回合数限制）时容易吃亏

**需要的护栏**：给体修的反击系数要 attacker 的伤害计入，且不能超过某个比例，
否则高血量体修会变成「站着不动也能赢」，伤害玩法失去意义。

## 六、分支点：三次抉择与各自的优缺点

抉择点绑定大境界，而不是等级：

| 抉择点 | 触发境界 | 内容 | 可否反悔 |
| --- | --- | --- | --- |
| 初择 | 筑基 | 四派选一 | 免费洗一次（避免误选锁死） |
| 进阶 | 结丹 | 本派二选一子分支 | 付费/道具洗点 |
| 道心 | 元婴 | 专精深化 或 跨派小幅融合 | 不可逆（形成长期差异） |

**初择（筑基）——四派**
代价是**只拿一派的加成**，且会立即错过其他三派的机制收益。
这是全局最重要的一次选择，所以要给一次免费洗的机会。

**进阶（结丹）——每派两条子分支**

| 流派 | 甲支（主进攻/效率） | 乙支（主生存/特殊） | 取舍要点 |
| --- | --- | --- | --- |
| 剑修 | 快剑：速度、暴击、追加攻击 | 重剑：单次高伤、更高穿透 | 快剑吃幸运/速度收益平稳；重剑爆发高但面对高格挡目标收益打折 |
| 丹修 | 药王：丹毒上限、炼制品级 | 毒修：把丹毒转为伤害/削弱目标 | 毒修很有仙侠味，但必须防「自毒换输出」变成无脑最优解 |
| 符修 | 御器：法宝增伤、法力续航 | 制符：控制成功率、视野与侦测 | 御器偏数值；制符偏功能，是符修的真正特色所在 |
| 体修 | 金身：防御、格挡、免控 | 血海：气血压榨、吸血与反击 | 金身更稳；血海输出更高但失去部分坦度，换来上限与风险 |

**道心（元婴）——不可逆**
两条路：

- **专精**：本派加成再上一档，但派内短板被进一步放大（剑修更脆、体修输出更低）
- **融合**：拿一个其他流派的小幅次级能力（例如剑修拿丹修的一点点丹毒耐受），
  代价是本派主加成打折

道心不可逆的意义是让高境界角色产生**真实差异**，而不是所有人都趋同到同一套数值模板。

## 六点五、基于标杆对标的修订（见 `benchmark-gbsh-ynxy.md`）

对标《鬼谷八荒》与《一念逍遥》后，本评定需修订如下，**后续实施以修订版为准**：

1. **初择改为「斗战 / 长生」二元**，结丹再分化为剑、体 / 丹、符。
   依据：一念逍遥开局实际只有炼体与修法两条主修，四条路线是后期才铺开的。
   这样新手决策负担更小，也让选择有递进感。

2. **流派强弱随境界阶段反转，不再写死优缺点**。
   依据：玩家经验是「返虚前体修碾压法修，返虚后法修反超」。
   流派加成应从「恒定 +15%」改为**随大境界变化的收益曲线**。

3. **新增第二条构筑线「逆天改命」**：每次大境界突破从气运池三选一。
   依据：这是鬼谷八荒公认最出色的设计，且词条跨流派随机才产生构筑感。
   本项目气运表（63 条）、突破流程、到期回滚均已具备，改动极小。

4. **每派设计一个「质变点」道具或神通**，而不是线性加成到终局。
   依据：一念逍遥体修被公认的质变点是「封魔困龙手」（免控 + 增伤）。

## 七、评定结论与落地建议

**优先顺序**：体修 ≈ 剑修 ＞ 丹修 ＞ 符修（按「现有公式能承载」的容易程度排）。

- 体修、剑修：所有需要的属性与机制都已存在，只需要 percent 层与两个专属机制
  （反击、连携），改动最小、公式零改动
- 丹修：需要动丹毒上限与炼品级，涉及 `pill-toxicity` 与 `alchemy`，但都是已有参数
- 符修：**必须先解决神识 → 治疗的错位**，否则做出来的是个奶妈。建议先定死
  「符修的神识不进治疗公式」这条规则，再谈流派

**统一的护栏**（四条流派都必须遵守）

1. 流派加成一律走**已落成的 percent 修饰层**，禁止写回基础属性（避免与其他模块重复）
2. 单一流派的总百分比收益控制在 **±15% 以内**，主要差异靠**专属机制**而不是数值
3. 任何涉及穿透、格挡、治疗的参数，都要尊重现有 `SOFT_CAP`，超出部分不再线性生效
4. 派别克是**收益结构上的差异**（剑修克体修、体修耗赢丹修、丹修磨死符修、符修遛死剑修），
   而不是单纯的数值压制

按照这个顺序落地，第一步建议做**体修 + 剑修**，因为它们零公式改动即可上线，
能最快验证「流派是否真的带来差异化体验」，再回头补丹修、符修。
