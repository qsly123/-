# Mock数据验证（2026-10-19）

结果：12项测试通过、53个断言通过。包含3项纯规则测试及9项mock集成场景。

## 验证方法

- mock数据库库存读取、其他养成系统输出，不提供真实数据库连接。
- 实际调用装备provider、`buildPlayerStatsSnapshot`、属性修饰器和`calculateCombatDamageOutcome`。
- mock查询严格按select字段投影；漏查stageMult不能由fixture隐式补齐。任何SQL执行或写库调用直接报错。
- 伤害场景固定随机数为0.5，同境界、无防御/暴击/格挡，技能倍率为1，用于隔离装备修正；不作为战斗胜率或难度结论。
- mock库存代表已筛选的合法装备；不验证Drizzle生成的SQL、境界过滤、事务、真实其他provider、实时通信或完整技能轮换。

## 结果

| 场景 | 结果 |
|---|---|
| 裸装 | 攻击100，伤害100，HP/MP不被自动恢复 |
| 25级武器无精炼 | 攻击14008，增伤5%，伤害14708 |
| 25级武器精炼10级 | 攻击20962，伤害22010；精炼只追加一次 |
| 精炼10级+旧/新增伤词条 | 两种快照完全一致，增伤7%，伤害22429 |
| 零基础增伤词条 | 神通伤害102，法宝增伤11%时法宝伤害111 |
| 精炼+固定攻击词条+攻击百分比+灵根 | 最终攻击25166.4，符合先加后乘规则 |
| 武器+护甲均精炼10级 | 攻击20962，HP上限106081，当前HP仍1000 |
| 零基础减伤词条 | 减伤2%，承伤98，HP由1000降到902 |
| 护盾及致死结算 | MP先消耗至0，HP归0，不出现负值 |

相同无精炼武器fixture按修正前规则计算的固定历史对照：增伤1288%、伤害194431；修正后增伤5%、伤害14708。历史数值为旧规则fixture基线，本轮不运行旧版完整服务。
